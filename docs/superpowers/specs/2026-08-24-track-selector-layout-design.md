# 技术分路选择器布局修复

## 目标

修复约 701–1024px 宽度下技术分路选择项的文字挤压和重叠问题，保持现有工业风视觉、文案和交互行为不变。

## 方案

- 平板断点继续使用双列选择器；每个选择项使用稳定的编号、名称和状态标记分栏。
- 将英文副标题从平板紧凑行中隐藏，避免长英文撑开布局。
- “限专业”状态继续定位在选择项右上角，不参与正文网格排版。
- 底部状态说明使用可换行布局并增加间距，避免 `SIGNALS EXPOSED` 与统计信息粘连。
- 手机断点继续使用单列选择器，并保持现有字号和间距层级。

## 范围

只修改 `src/styles.css` 的技术分路选择器响应式样式，不修改 React 组件、数据或交互逻辑。

## 验证

- 执行 `npm run build`。
- 执行现有 Vitest 测试。
- 在桌面和平板宽度检查选择项无水平溢出、文字重叠和布局跳动。
